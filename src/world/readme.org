* World
** Country data
- https://www.naturalearthdata.com/
- The app only loads the generated =assets/countries-{10m,50m,110m}.json=, no
  external sites.
- To update them:
  - =uv run src/download-data.py= downloads Natural Earth's countries, map
    units and populated places into =data/=
  - =uv run src/prepare-data.py= writes =assets/countries-{10m,50m,110m}.json=
